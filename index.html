05 · RECOMMENDATION SYSTEM · RESTAURANTS

Swiggy Restaurant Recommendation System

Content-based restaurant recommendation system that suggests restaurants based on cuisine, city, budget and rating using engineered features and cosine similarity.

PythonPandasNumPyScikit-learnSciPyStreamlit
Content-based personalized recommendations
View full project details ＋

Problem Statement

Users often struggle to find restaurants matching their preferences among thousands of options. This project simplifies the decision-making process with personalized recommendations.

Data Preprocessing

  • Handled missing values
  • Cleaned and standardized cuisine data
  • Split multiple cuisines using explode()
  • Capped outliers using 99th-percentile quantile capping

Feature Engineering

  • Numerical features: rating, rating count and cost
  • Cost scaled using StandardScaler
  • Categorical features: city and cuisine
  • Categorical values encoded using OneHotEncoder
  • Numerical and categorical features combined using sparse feature stacking

Recommendation Engine

Cosine similarity is used to identify restaurants most similar to the user's selected preferences.

Run Locally

streamlit run swiggy_app.py
